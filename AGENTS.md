# For coding agents

This is the ohm UI, built from scratch. It does not import code from `ohm-content-layer` or `ohm-1`.

- Every colour, size, radius, space and duration is an `--ohm-*` token from `src/design/tokens.css`. No raw values in components or CSS.
- Icons are Lucide (`lucide-react`).
- Run `npm run typecheck` and `npm run build` after changing code.
